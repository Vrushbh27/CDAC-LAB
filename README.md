# CDAC — Course Materials Repository

A study and reference collection of lab exercises, lecture notes, and practice projects completed during the **CDAC (Centre for Development of Advanced Computing)** programme. Content is organised by subject area and further broken down by day/session.

---

## 📂 Repository Structure

| **Folder** | **Description** |
|---|---|
| `C_CPP_LAB` | C and C++ programming labs and exercises |
| `Core_Java` | Core Java fundamentals, collections, and multithreading |
| `ADVANCED_JAVA` | Advanced Java topics (Servlets, JSP, frameworks) |
| `DBT_DatabaseTech` | Database technology — SQL, PL/SQL, and DBMS concepts |
| `DataStructure` | Data structures implementations and practice problems |
| `OS` | Operating systems concepts and shell scripting |
| `Devops` | DevOps tools — Git and Docker |
| `MS_DOT_NET` | Microsoft .NET — C#, MVC, and full-stack project |
| `WebProgramingTechnologies` | Web technologies — HTML, CSS, JavaScript, and React |
